# What to Teach Before Acting

Project website for *What to Teach Before Acting: Revisiting Embodied VQA for VLA Models*.

Published at https://markyyds.github.io/what-to-teach-before-acting/.

This repository contains the static website snapshot from version 13. Open `index.html` through a static HTTP server to preview it. GitHub Pages publishes the repository root from `main`.

Episode videos, extracted evidence and question examples are recorded pipeline outputs. The browser does not run perception models. Dataset attribution and links are included on the website.
